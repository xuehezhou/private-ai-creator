# 产品路线图

## 📍 当前版本：V1.0

基于 AI-Douyin-Agent 桌面应用版本，已完成核心内容生产闭环。

---

## 路线图时间线

```
[已完成] ──► [已完成] ──► [已完成] ──► [进行中] ──► [规划中]
   V1.0        V1.1        V1.2        V1.5        V2.0
```

### V1.0 — 无代码验证（已完成 ✅）

- 使用 Claude Projects / GPTs 进行文档级验证
- 验证内容模板、文案公式、人设定位的可行性
- 输出：完整的提示词系统 + 内容模板库

### V1.1 — Python 半自动化桌面应用（已完成 ✅）

- tkinter GUI 桌面应用
- 离线模板引擎（0 token，断网可用）
- 图片上传、文案生成、BGM 推荐
- 固定封面模板 + 代码标签自动打图
- 发布记录自动存档

### V1.2 — 自动发布能力（已完成 ✅）

- Playwright 浏览器自动化
- AI Vision 视觉识别 + 键盘导航双重兜底
- 自动填充标题/文案/上传图片
- 三级降级策略（AI Vision → DOM 选择器 → 坐标兜底）

### V1.5 — 精细化运营（当前重点 🔄）

- 每张照片独立标记控制
- AI 标记建议
- 多代码截图支持
- 草稿自动保存
- 文案直接编辑（Ctrl+S 保存）
- 14 首抖音热门 BGM 自动匹配

### V2.0 — 真 Agent 架构（规划中 📋）

- FastAPI 后端 + 多智能体协作
- 选题 Agent：自动分析热点 + 个人定位 → 推荐选题
- 复盘 Agent：自动分析发布数据 → 给出优化建议
- 数据分析 Agent：粉丝画像、互动趋势分析
- 热点追踪 Agent：实时监测行业热点
