## 🎯 项目定位

私人AI创作助手是一套面向个人创作者的内容生产自动化系统，聚焦以下场景：

- **AI 学习记录**：每周学习内容系统化产出短视频内容
- **编程学习过程**：代码截图自动打标签，建立专业信任感
- **个人成长记录**：真实、不包装的成长轨迹

## 🚀 核心价值

| 痛点 | 解决方案 |
|---|---|
| 每周要花大量时间想文案 | 输入主题 → 1秒生成文案 |
| 封面每期都要重新设计 | 固定模板，改字就出图 |
| 代码图不知道怎么配文 | 自动分析代码含义，打标签 |
| 不知道配什么BGM | 14首热门曲库，按情绪自动匹配 |
| 发布流程繁琐 | Playwright 自动填充，确认即发布 |

## 🔑 Token 最小化设计

| 模式 | 消耗 | 说明 |
|---|---|---|
| 离线模板引擎（默认） | **0 token** | 内置模板 + 规则引擎，断网可用，1 秒出结果 |
| API 润色（可选） | 约 800 token/次 | 在配置中填 API Key 开启，失败自动回退离线 |

## 🛡️ 安全原则

- 发布前必须经过人工审核确认
- 不保存任何平台账号密码
- 限制自动操作频率
- 完整记录操作日志
