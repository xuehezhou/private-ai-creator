## 4. 三级降级策略（发布执行）

```
┌─────────────────────────────────────────┐
│           发布执行降级策略               │
├─────────────────────────────────────────┤
│                                         │
│  第一级：AI Vision 视觉识别              │
│  ┌─────────────────────────────────┐    │
│  │ DeepSeek/GPT Vision 截图识别     │    │
│  │ 识别输入框、按钮位置              │    │
│  │ 成功率：> 85%                    │    │
│  └─────────────────────────────────┘    │
│              ↓ 失败                     │
│  第二级：DOM 选择器定位                  │
│  ┌─────────────────────────────────┐    │
│  │ Playwright 元素选择器            │    │
│  │ 通过 data-testid / class 定位    │    │
│  │ 成功率：> 70%                    │    │
│  └─────────────────────────────────┘    │
│              ↓ 失败                     │
│  第三级：坐标兜底                        │
│  ┌─────────────────────────────────┐    │
│  │ 预设屏幕坐标 + 相对偏移          │    │
│  │ 适用于固定分辨率                  │    │
│  │ 成功率：> 50%                    │    │
│  └─────────────────────────────────┘    │
│                                         │
│  全部失败 → 停在当前页面，通知用户手动完成 │
│                                         │
└─────────────────────────────────────────┘
```

## 5. 数据流架构

```
用户输入
  │
  ├──► draft.json (草稿自动保存)
  │
  ├──► 内容生成引擎
  │      ├──► 离线模板 (0 token)
  │      └──► API 润色 (可选, ~800 token)
  │
  ├──► output/第N周/ (成品包)
  │      ├──► 封面图
  │      ├──► 打标签代码图
  │      ├──► 生活照
  │      └──► BGM 截取片段
  │
  ├──► 07_发布记录.xlsx (发布历史)
  │
  └──► 抖音创作者中心 (最终发布)
```
