# Prompt 版本记录 · V1.0

> 时间：2026-07 初 | 状态：已废弃（被V1.1替代）

---

## V1.0 概述

V1.0 阶段完全运行在 Claude Projects / GPTs 中，无代码。

用户在对话框里输入主题和照片，AI直接生成文案。

## V1.0 Prompt 结构

```
系统角色：AI内容运营助手

输入：周数 + 主题 + 学习内容 + 照片描述
输出：标题 + 正文 + 标签 + 封面文字 + 音乐建议
```

## V1.0 问题

| 问题 | 影响 |
|------|------|
| 每次都要重新描述人设和风格 | 上下文浪费，输出不稳定 |
| 无法处理真实图片 | 只能描述照片内容，不能实际打标签 |
| 不能自动排版封面 | 封面需要手动在别的工具做 |
| 没有固定模板 | 每期输出格式不一致 |

## V1.0 → V1.1 改进

- 人设和风格固化到 `01_个人定位.md` 文档
- 搭建 Python tkinter 桌面应用
- 实现封面模板自动生成
- 实现代码标签自动叠加到图片
- 离线模板引擎（0 token，断网可用）
