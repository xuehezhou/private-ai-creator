# Prompt 版本记录 · V2.0

> 2026-07-31

---

## 变更概要

从 V1.x 升级到 V2.0，核心变更：

### 1. 内容生成Agent 系统 Prompt 全面升级

**之前（V1.x）：**
- 简短的几段话，约40行
- 没有标准化的输出格式定义
- 没有与执行发布Agent的对接说明

**现在（V2.0）：**
- 完整的角色定义、能力描述、内容原则
- 详细的输出格式规范（→ `publish_package.json`）
- 明确的"输出到文件系统"章节
- 完整的"与执行发布Agent对接协议"

### 2. 执行发布Agent 系统 Prompt 增强

**新增：**
- "输入来源"章节：明确从哪里读取素材包
- 素材包格式完整定义
- 读取后第一步校验流程
- "与内容生成Agent的对接协议"章节
- 职责边界清晰划分

### 3. generator.py 更新

- `_load_system_prompt()` 优先级调整为：`04_Prompt提示词/系统Prompt/内容Agent` → `02_个人知识库/我的创作者档案.md` → 内置默认
- 内置默认 Prompt 与权威 Prompt 文件保持一致
- 年龄/账号名默认值更新为 22岁

### 4. 设计文档同步

- `03_Agent设计/内容生成Agent/Agent说明.md` 更新至 V2.0

---

## 关键改进：两个Agent的对接

```
之前：内容Agent → 素材包 → (无明确协议) → 执行Agent
现在：内容Agent → publish_package.json → (校验+交接清单) → 执行Agent
```

`publish_package.json` 现在是两个Agent之间的**标准化合约**：
- 内容Agent 必须按格式输出
- 执行Agent 先校验再执行
- 用户可以在中间审核和修改
