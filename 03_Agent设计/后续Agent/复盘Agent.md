# 复盘Agent · 设计框架

> 版本：V2.0 规划 | 状态：设计中 | 2026-07-31

---

## 一、Agent 职责

### 一句话职责

**复盘Agent = 自动分析已发布内容的数据表现 → 给出内容优化建议 → 沉淀可复用的经验到知识库。**

### 核心能力

| # | 能力 | 说明 |
|---|------|------|
| 1 | **数据采集** | 读取抖音作品数据（播放量、点赞、评论、分享、收藏） |
| 2 | **对比分析** | 与历史作品对比，找出表现异常（好/差）的内容 |
| 3 | **原因推断** | 结合内容特征（标题、钩子、发布时间、选题）分析原因 |
| 4 | **优化建议** | 给出具体可执行的改进建议 |
| 5 | **知识沉淀** | 将验证有效的模式写入爆款分析库 |

---

## 二、复盘维度

| 维度 | 分析内容 |
|------|---------|
| **选题** | 这个话题是否有受众？与账号定位的匹配度？ |
| **标题** | 点击率如何？标题是否有吸引力？ |
| **钩子** | 前3秒留存率？钩子是否有效？ |
| **文案** | 完读率？文案结构是否合理？ |
| **视觉** | 封面图点击率？图片质量？ |
| **时间** | 发布时间是否合适？ |
| **互动** | 评论内容分析？观众在讨论什么？ |

## 四、数据来源

V2.0 初期采用手动模式：
1. 用户周日截图抖音作品数据
2. 复盘Agent读取截图 + OCR提取数据
3. 自动生成复盘报告

V2.0 后期探索：
- 抖音开放平台API（如有）
- Playwright自动采集

## 五、与爆款分析库的联动

复盘Agent发现的**可复用模式** → 自动写入 `07_数据资产/爆款案例/`：

```
复盘Agent 分析第30周数据
    │
    ▼
发现：数字型标题点击率 +30%
    │
    ▼
自动写入爆款分析库：
  "标题公式：数字+对比型标题适合AI学习类内容"
    │
    ▼
下次选题Agent生成标题时 → 优先使用该公式
```
