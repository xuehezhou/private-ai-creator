# 选题Agent · 设计框架

> 版本：V2.0 规划 | 状态：设计中 | 2026-07-31

---

## 一、Agent 职责

### 一句话职责

**选题Agent = 自动分析热点趋势 + 结合个人定位 + 知识库素材 → 推荐本周最优选题。**

### 核心能力

| # | 能力 | 说明 |
|---|------|------|
| 1 | **热点分析** | 监测抖音AI/编程领域的 trending topics |
| 2 | **个人匹配** | 结合个人定位（真实/学习记录/不装专家）过滤不适合的选题 |
| 3 | **素材感知** | 读取素材库，判断是否有足够的照片/截图支撑该选题 |
| 4 | **选题推荐** | 每周一自动给出3个候选选题 + 推荐理由 |
| 5 | **历史去重** | 避免与已发布内容重复 |

---

## 二、选题来源

| 来源 | 权重 | 说明 |
|------|------|------|
| 个人学习计划 | ⭐⭐⭐⭐⭐ | 优先级最高——学什么就拍什么 |
| 上周学习延伸 | ⭐⭐⭐⭐ | 自然延续，形成系列感 |
| 热点话题 | ⭐⭐⭐ | 借势但不生搬，必须和个人定位有关 |
| 爆款分析库 | ⭐⭐⭐ | 从采集的爆款中找可复用的选题角度 |
| 粉丝评论/私信 | ⭐⭐ | 回应观众真实关心的问题 |

---

## 三、选题过滤规则

自动排除不符合定位的选题：

- ❌ 超出当前能力范围（"手写Transformer"但还没学到）
- ❌ 与"真实记录"定位冲突（需要表演/包装的）
- ❌ 纯搬运/资讯类（没有个人实操的）
- ❌ 已做过类似内容（90天内）
