## 异常分类体系

```
异常
├── A类：可自动恢复（重试策略）
│   ├── A1 页面加载超时
│   ├── A2 DOM元素未找到
│   ├── A3 操作被阻塞（弹窗/蒙层）
│   └── A4 网络瞬时中断
│
├── B类：需人工介入（暂停+提示）
│   ├── B1 未登录/登录过期
│   ├── B2 上传文件被拒绝（格式/大小）
│   ├── B3 平台限流/验证码
│   └── B4 输入内容被平台拦截
│
└── C类：致命错误（终止流程）
    ├── C1 浏览器无法启动
    ├── C2 素材包损坏
    └── C3 重试耗尽
```

## A类异常：自动恢复

### A1 页面加载超时

```
症状：导航后30秒仍无发布表单
检测：page.wait_for_selector(目标元素, timeout=30000) 抛出 TimeoutError

恢复策略（最多3次）：
  第1次：page.reload() 刷新页面
  第2次：page.goto(发布页URL) 重新导航
  第3次：关闭浏览器 → 重新启动 → 重新导航

3次均失败 → 升级为C3（重试耗尽）
```

### A2 DOM元素未找到

```
症状：选择器无法定位到目标元素
检测：page.locator(选择器).count() == 0

恢复策略：
  1. 尝试候选选择器列表（selector_map.json中按优先级排列）
  2. 所有DOM选择器失败 → 启用AI Vision识别
  3. AI Vision识别失败 → 等待2秒后重试（可能页面未渲染完）
  4. 仍失败 → 升级为A1（刷新页面）

选择器尝试顺序（以标题输入框为例）：
  [
    "input[placeholder*='标题']",
    "[data-testid='title-input']",
    ".title-input input",
    "input[maxlength='55']",
    "[class*='title'] input"
  ]
  → 全部失败 → AI Vision识别
```

### A3 操作被阻塞

```
症状：点击/输入无效，页面出现弹窗或蒙层
检测：截图 → AI判断是否有弹窗/蒙层

常见阻塞场景：
┌──────────────────────┬────────────────────────┐
│ 阻塞物               │ 处理方式                 │
├──────────────────────┼────────────────────────┤
│ 新手引导弹窗         │ 点击"知道了"/"跳过"     │
│ 公告/活动弹窗        │ 点击关闭按钮或蒙层区域   │
│ 功能提示tooltip      │ 点击空白区域关闭         │
│ 未保存草稿提示       │ 选择"继续"              │
│ 图片上传中蒙层       │ 等待上传完成             │
└──────────────────────┴────────────────────────┘

处理流程：
  1. 截图识别弹窗类型
  2. 执行对应关闭操作
  3. 等待500ms
  4. 重试原操作
```

### A4 网络瞬时中断

```
症状：page.goto()或API请求返回网络错误
检测：Playwright抛出 net::ERR_* 错误

恢复策略：
  1. 等待3秒（网络恢复）
  2. 重试原操作
  3. 仍失败 → 等待10秒
  4. 仍失败 → 升级为C3

日志记录：
  {
    "error": "NETWORK_INTERRUPTION",
    "url": "https://creator.douyin.com/...",
    "retry_attempt": 2,
    "timestamp": "..."
  }
```

## B类异常：人工介入

### B1 未登录/登录过期

```
症状：访问创作者中心被重定向到登录页
检测：page.url 包含 "login" 或 页面有"扫码登录"元素

处理流程：
  1. 截图当前登录页面
  2. 暂停自动化流程
  3. 显示提示：

  ┌─────────────────────────────────────┐
  │  ⚠️ 检测到未登录                     │
  │                                     │
  │  请在浏览器中扫码登录抖音创作者中心    │
  │  登录完成后，在此窗口输入 y 继续      │
  │  或输入 n 取消发布                   │
  └─────────────────────────────────────┘

  4. 等待用户输入
  5. y → 重新检查登录态 → 继续流程
  6. n → 终止流程，保存当前状态
```

### B2 上传文件被拒绝

```
症状：上传后平台提示"格式不支持"或"文件过大"
检测：页面上出现错误提示文案

常见原因与处理：
┌──────────────────────┬──────────────────────────┐
│ 原因                 │ 处理                      │
├──────────────────────┼──────────────────────────┤
│ 图片格式不支持        │ 自动转换为PNG后重试       │
│ 图片文件过大          │ 自动压缩后重试            │
│ 图片尺寸不符          │ 自动裁剪/缩放后重试       │
│ 图片数量超限          │ 截取前35张，提示用户       │
└──────────────────────┴──────────────────────────┘

自动转换脚本：
  from PIL import Image
  img = Image.open(原图)
  # 压缩到20MB以内
  img.save(临时文件, 'PNG', optimize=True)
  # 重试上传

转换失败 → 提示用户手动处理该图片
```

### B3 平台限流/验证码

```
症状：弹出滑块验证码或"操作频繁"提示
检测：截图 → AI识别验证码或限流提示

处理流程：
  1. 截图保存
  2. 暂停全部操作
  3. 提示用户：

  ┌─────────────────────────────────────┐
  │  ⚠️ 平台安全验证                     │
  │                                     │
  │  抖音要求进行安全验证（验证码/滑块）   │
  │  请在浏览器中手动完成验证             │
  │  完成后输入 y 继续                   │
  └─────────────────────────────────────┘

  4. 用户确认后 → 检查是否已解除 → 继续
  5. 添加操作间隔（所有延迟翻倍），降低触发概率
```

### B4 输入内容被平台拦截

```
症状：标题/正文填入后，平台显示红色错误提示
检测：截图中出现红色警告文案

常见拦截原因：
  - 标题包含敏感词
  - 正文包含联系方式（微信/QQ/手机号）
  - 内容触发平台审核规则

处理流程：
  1. 截图错误提示区域
  2. 解析具体拦截原因
  3. 报告用户：

  ┌─────────────────────────────────────┐
  │  ⚠️ 内容被平台拦截                   │
  │                                     │
  │  原因：标题包含敏感词 "xxx"           │
  │  建议：修改该词后重试                 │
  │                                     │
  │  是否自动去除该词后重试？(y/n)       │
  └─────────────────────────────────────┘

  4. y → 自动去除敏感词 → 重新填入
  5. n → 由用户在浏览器中手动修改
```

## C类异常：致命错误

### C1 浏览器无法启动

```
症状：Playwright 抛出 BrowserType.launch 错误
常见原因：
  - Chromium未安装：playwright install chromium
  - 端口被占用：检查9222端口
  - 权限不足

处理：
  1. 尝试安装缺失依赖：
     subprocess.run(["playwright", "install", "chromium"])
  2. 重试启动
  3. 仍失败 → 终止，生成错误报告
```

### C2 素材包损坏

```
症状：JSON解析失败或必填字段缺失
检测：json.load() 抛出异常 或 校验失败

处理：
  1. 解析具体哪一项校验失败
  2. 生成详细错误报告：

  {
    "error": "PACKAGE_CORRUPTED",
    "details": [
      {"field": "content.title", "issue": "标题为空"},
      {"field": "images[1].file", "issue": "文件不存在: xxx.png"}
    ],
    "suggestion": "请在内容生成Agent中重新生成素材包"
  }

  3. 终止流程，不做重试
```

### C3 重试耗尽

```
症状：某个步骤重试3次后仍失败
检测：retry_counter >= 3

处理：
  1. 截取当前页面状态
  2. 记录完整执行日志（到哪个步骤、尝试了什么方案）
  3. 生成手动发布指南：

  ┌─────────────────────────────────────┐
  │  ❌ 自动发布未完成                   │
  │                                     │
  │  已完成：✅ 图片上传 ✅ 标题填写      │
  │  未完成：❌ 标签添加                 │
  │                                     │
  │  手动完成步骤：                      │
  │  1. 在浏览器中继续操作              │
  │  2. 添加标签：AI学习、Python入门     │
  │  3. 检查无误后点击发布               │
  │                                     │
  │  📸 当前页面截图已保存               │
  └─────────────────────────────────────┘

  4. 保存发布报告（status: partial_complete）
  5. 浏览器保持打开，不关闭
```

## 全局异常捕获

```python
# 主流程异常捕获伪代码

try:
    run_publish_workflow(package_path)

except PackageValidationError as e:
    # C2: 素材包损坏
    handle_fatal(e, "素材包校验失败")

except BrowserLaunchError as e:
    # C1: 浏览器无法启动
    handle_fatal(e, "浏览器启动失败")

except LoginRequiredError:
    # B1: 未登录
    handle_login_required()

except RateLimitError:
    # B3: 限流
    handle_rate_limit()

except ContentBlockedError as e:
    # B4: 内容被拦截
    handle_content_blocked(e)

except UploadError as e:
    # B2: 上传失败 → 尝试自动修复
    handle_upload_error(e)

except (TimeoutError, ElementNotFoundError) as e:
    # A类: 可恢复 → 重试
    retry_or_escalate(e)

except RetryExhaustedError:
    # C3: 重试耗尽
    handle_retry_exhausted()

except Exception as e:
    # 未知异常
    screenshot_current_page()
    save_error_log(e)
    notify_user(f"未知错误: {e}")
```
