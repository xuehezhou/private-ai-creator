## 每步详细操作

### STEP 1：加载素材包

```python
# 伪代码
package_path = f"output/第{week_num}周/publish_package.json"
package = json.load(open(package_path, 'r', encoding='utf-8'))

# 提取关键数据
title = package['content']['title']
body = package['content']['body']
tags = package['content']['tags']
images = [img['file'] for img in package['images']]
```

### STEP 2：素材校验

| 校验项 | 规则 | 失败处理 |
|--------|------|---------|
| 图片文件 | 每个 `file` 路径文件存在 | 返回缺失文件列表 |
| 图片数量 | 1 ≤ count ≤ 35 | 返回"图片数量超限" |
| 图片格式 | jpg / png / webp | 返回不合规文件列表 |
| 图片大小 | 每张 ≤ 20MB | 返回超限文件列表 |
| 标题字数 | 1 ≤ len ≤ 55 | 返回"标题过长/过短" |
| 正文字数 | 1 ≤ len ≤ 1000 | 返回"正文过长/过短" |
| 标签数量 | 1 ≤ count ≤ 5 | 返回"标签数量超限" |
| 标签字数 | 每个 ≤ 10字 | 返回超限标签 |

### STEP 3：启动浏览器

```
启动参数：
  - channel: chromium
  - headless: false（用户需要看到浏览器）
  - user_data_dir: ~/.claude/douyin_user_data/
  - viewport: 1280x800

登录态检查：
  访问 creator.douyin.com
  → 如果URL包含 "login" 或页面有"扫码登录"字样
  → 判定为未登录
  → 提示用户："请先在浏览器中扫码登录，登录完成后按回车继续"
  → 等待用户确认后重新检查
```

### STEP 4：导航至发布页

```
目标URL：https://creator.douyin.com/creator-micro/content/upload

等待条件（满足任一即继续）：
  1. 页面中出现 "发布" 按钮
  2. 页面中出现文件上传区域
  3. 页面 title 包含 "发布"

超时处理：
  30秒超时 → 刷新页面（page.reload()）
  再超时 → 再刷新
  3次仍超时 → 终止，报 NAVIGATION_FAILED
```

### STEP 5：上传图片

```
三级降级（按顺序尝试）：

═══════════════════════════════════════════
第一级：input[type=file] 直接设置文件
═══════════════════════════════════════════
  1. 查找隐藏的 <input type="file" accept*="image">
  2. 调用 input.set_input_files([图片路径列表])
  3. 等待上传进度完成（检测loading元素消失）
  4. 验证：截图上是否出现了图片缩略图

  ✅ 成功 → 进入STEP 6
  ❌ 失败 → 进入第二级

═══════════════════════════════════════════
第二级：点击上传按钮 + 文件选择对话框
═══════════════════════════════════════════
  1. 截图当前页面
  2. AI Vision识别"上传"或"+"按钮坐标
  3. 点击该坐标
  4. 等待文件选择对话框出现
  5. 通过 page.on('filechooser') 设置文件
  6. 等待上传完成
  7. 验证图片缩略图

  ✅ 成功 → 进入STEP 6
  ❌ 失败 → 进入第三级

═══════════════════════════════════════════
第三级：纯AI Vision坐标点击
═══════════════════════════════════════════
  1. 全页截图
  2. 发送给Claude/GPT Vision：
     "找到抖音图文发布页的上传图片按钮/区域，
      返回中心点的(x, y)坐标"
  3. 在返回坐标上点击
  4. 等待2秒
  5. 截图验证

  ✅ 成功 → 进入STEP 6
  ❌ 失败 → 终止流程，保存当前截图，通知用户
```

### STEP 6：填写标题

```
1. 定位标题输入框
   - DOM选择器：input[placeholder*="标题"], input[maxlength="55"]
   - 备选：AI Vision识别"标题"标签附近的input

2. 清空已有内容
   - input.click()
   - page.keyboard.press('Control+a')
   - page.keyboard.press('Delete')

3. 填入标题
   - 优先粘贴：page.keyboard.insert_text(title)
   - 粘贴失败 → 逐字输入

4. 验证
   - 读取 input.value
   - 对比 title
   - 不匹配 → 重试1次
```

### STEP 7：填写正文

```
1. 定位正文编辑区
   - DOM选择器：[contenteditable="true"], .rich-text-editor
   - 备选：AI Vision识别

2. 清空 + 填入（同STEP 6逻辑）

3. 特殊处理：
   - 正文中的换行符\n → Shift+Enter（或依赖粘贴自动处理）
   - 正文中的emoji → 保持原样（粘贴时自动保留）

4. 验证后继续
```

### STEP 8：添加标签

```
1. 定位标签输入框
   - DOM选择器：[placeholder*="标签"], .tag-input input

2. 逐个添加标签：
   for tag in tags:
       a. 点击标签输入框
       b. 输入标签名（逐字输入，触发平台下拉建议）
       c. 等待500ms
       d. 查找下拉建议中的匹配项
       e. 如果有匹配项 → 点击选择
       f. 如果没有匹配项 → 直接回车确认（创建新标签）
       g. 等待500ms
       h. 验证标签已添加（截图中可见标签chip/气泡）

3. 全部添加后 → 验证标签数量 = 目标数量
```

### STEP 9：发布前自检

```
检查项与验证方法：

┌────────────┬──────────────────────────────────┐
│  检查项     │  验证方法                         │
├────────────┼──────────────────────────────────┤
│ 图片数量    │ 截图 → AI识别缩略图数量            │
│            │ 或 DOM查询缩略图元素数量            │
├────────────┼──────────────────────────────────┤
│ 标题内容    │ JavaScript读取标题输入框value       │
│            │ 与目标title字符串对比               │
├────────────┼──────────────────────────────────┤
│ 正文内容    │ JavaScript读取正文编辑器内容         │
│            │ 与目标body对比（忽略尾部空格/换行）   │
├────────────┼──────────────────────────────────┤
│ 标签完整性  │ 截图 → AI识别标签chip数量           │
│            │ 或 DOM查询标签元素数量              │
└────────────┴──────────────────────────────────┘

结果处理：
- 全部通过 → 进入STEP 10
- 任一不通过 → 修正差异项 → 重新检查（最多2轮）
```

### STEP 10：截图 + 通知

```
1. 截取全页面截图
   screenshot = page.screenshot(full_page=True)
   save_path = f"{output_dir}/发布预览_{timestamp}.png"
   screenshot.save(save_path)

2. 复制截图到剪贴板（方便用户预览）
   PowerShell: Set-Clipboard -Value 图片

3. 生成发布报告
   → publish_report_{timestamp}.json

4. 显示摘要通知：
   ┌──────────────────────────────────┐
   │  ✅ 发布内容已填入完毕            │
   │                                  │
   │  📝 标题：xxx...                 │
   │  🖼️ 图片：3张                   │
   │  🏷️ 标签：#AI学习 #Python       │
   │                                  │
   │  ⚠️ 请检查后手动点击"发布"按钮   │
   │  📸 预览截图已保存               │
   └──────────────────────────────────┘

5. 浏览器保持打开，不自动关闭
   用户可以：
   - 在浏览器中查看/修改内容
   - 点击"发布"完成最终发布
   - 关闭浏览器取消发布
```
