# 内容生成Agent · 输入输出格式

> 版本：V1.5 | 定义内容生成Agent的标准输入输出

---

## 一、输入格式

### 用户输入（GUI表单）

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 周数 | int | ✅ | 第N周，如 30 |
| 本周主题 | string | ✅ | 一句话概括，如"用AI三小时学完Python基础" |
| 学了什么 | string | ✅ | 本周具体学习内容 |
| 完成了什么 | string | ❌ | 本周完成的成果 |
| 卡在哪 | string | ❌ | 遇到的困难/卡点 |
| 代码截图 | file[] | ✅ | 1-N张代码/项目截图 |
| 生活照片 | file[] | ❌ | 0-N张生活/学习照片 |

### 内部输入（JSON，程序内部传递）

```json
{
  "week": 30,
  "theme": "用AI三小时学完Python基础",
  "learning_content": "这周用DeepSeek辅助学习了Python的列表推导式、函数定义、文件读写",
  "completed": "写了一个自动整理桌面的脚本",
  "difficulties": "装饰器还没完全理解",
  "images": {
    "code_screenshots": ["path/to/code1.jpg", "path/to/code2.jpg"],
    "life_photos": ["path/to/life1.jpg", "path/to/life2.jpg"]
  }
}
```

### 字段说明

| 字段 | 类型 | 必填 | 约束 |
|------|------|------|------|
| `content.title` | string | ✅ | 1-55字（抖音图文标题限制） |
| `content.title_alternatives` | string[] | ✅ | 2个备选标题 |
| `content.hook` | string | ✅ | 3秒开场钩子 |
| `content.body` | string | ✅ | 短句分行体，10行左右 |
| `content.tags` | string[] | ✅ | 3-8个标签 |
| `content.cover_text` | string | ✅ | 封面叠字，≤15字 |
| `content.bgm` | object | ✅ | BGM推荐信息 |
| `images[].file` | string | ✅ | 绝对路径 |
| `images[].type` | enum | ✅ | `cover` / `code_with_tag` / `lifestyle` |
| `images[].tag_text` | string | ❌ | 仅 `code_with_tag` 类型需要 |

## 三、人工可修改

素材包生成后，用户可以在审核阶段：
1. 直接编辑 `publish_package.json` 修改标题/正文/标签
2. 替换输出目录中的图片文件
3. 在GUI中修改标签文字（🏷️ 标记页）
4. 在GUI中直接编辑文案（📝 文案页，Ctrl+S 保存）
