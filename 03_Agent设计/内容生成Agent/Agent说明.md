# 内容生成Agent · 设计说明

> 版本：V2.0 | 状态：已实现 | 2026-07-31

---

## 一、Agent 职责定义

### 一句话职责

**内容生成Agent = 接收用户输入（周数+主题+照片）→ 分析图片 + 策划内容角度 + 生成完整发布素材包（封面+打标签图+文案+BGM推荐）→ 输出 `publish_package.json` 交给执行发布Agent。**

### 核心职责

| # | 职责 | 说明 |
|---|------|------|
| 1 | **接收用户输入** | 周数、本周主题、学了什么、完成了什么、卡在哪、照片 |
| 2 | **图片内容理解** | 分析图片中的场景、事件、情绪、故事线 |
| 3 | **内容策划** | 思考为什么分享、对观众有什么价值、最适合的表达角度 |
| 4 | **生成文案** | 标题（3选1）、钩子、正文（短句分行体）、话题标签 |
| 5 | **生成封面** | 固定模板 + 本期主题/期数文字 |
| 6 | **代码打标签** | 分析代码截图含义，自动在图片上叠加标签文字 |
| 7 | **BGM推荐** | 从14首抖音热门曲库中按主题+情绪自动匹配top3 |
| 8 | **人设检查** | 对照《个人定位》红线自检，不通过则重写 |
| 9 | **输出素材包** | 打包为 `publish_package.json` + 图片文件，交给执行发布Agent |

### 实现方式

- **离线模板引擎**（`generator.py`）：0 token，1秒出结果，默认模式
- **API 增强模式**：填入 API Key 后调用大模型按系统Prompt润色（约800 token/次）
- **系统 Prompt**：`04_Prompt提示词/系统Prompt/内容Agent`（权威定义，V2.0）

## 二、工作流程

```
接收用户输入（主题 + 图片）
  ↓
① 图片内容理解 → 场景/情绪/故事线
  ↓
② 内容策划 → 匹配内容方向，确定表达角度
  ↓
③ 生成文案 → 标题(3选1) / 钩子 / 正文 / 标签
  ↓
④ 生成封面图 → 固定模板 + 主题文字
  ↓
⑤ 代码图打标签 → 分析代码含义 + 叠加标签
  ↓
⑥ 推荐BGM + 发布时间建议
  ↓
⑦ 人设红线检查 → 不通过重写
  ↓
⑧ 输出 publish_package.json → 等待用户审核
  ↓
⑨ 用户审核通过 → 执行发布Agent接管
```

## 三、与执行发布Agent的对接

```
内容生成Agent                    执行发布Agent
     │                                │
     │  写入 publish_package.json      │
     ├──────────────────────────────► │
     │                                │ 读取JSON
     │                                │ 校验完整性
     │                                │ 打开浏览器
     │                                │ 填入抖音发布页
     │                                │ 停在确认页
     │                                │
     ▼                                ▼
 output/第N周/                   抖音创作者中心
```

### 对接文件：`publish_package.json`

内容生成Agent输出此文件 → 用户审核 → 执行发布Agent读取此文件 → 填入抖音。

完整格式定义见 `04_Prompt提示词/系统Prompt/内容Agent` 末尾的「输出到文件系统」章节。

### 交接清单

内容生成Agent 写入 JSON 前必须确认：
- [ ] `content.title` 非空，1-55字
- [ ] `content.body` 非空
- [ ] `content.tags` 有3-8个标签
- [ ] `images[]` 中每个 `file` 路径真实存在
- [ ] `images[].type` 正确标注
- [ ] `output_dir` 是有效绝对路径
- [ ] JSON 格式正确，可被程序解析
