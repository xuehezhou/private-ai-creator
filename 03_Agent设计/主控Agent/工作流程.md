## 主控Agent调度流程

```
用户输入（主题 + 图片）
      │
      ▼
┌─────────────────────────────────────┐
│          主控Agent（任务管理）         │
│                                     │
│  1. 接收用户需求                     │
│  2. 判断任务类型                     │
│  3. 按序调度子Agent                  │
│  4. 整合最终结果                     │
│  5. 返回给用户确认                   │
└─────────────────────────────────────┘
      │
      │  按序调度
      ▼
┌─────────────────────────────────────┐
│  图片分析Agent                       │
│  → 分析场景/情绪/故事线              │
│  → 输出图片描述JSON                  │
└──────────────┬──────────────────────┘
               │
               ▼
┌─────────────────────────────────────┐
│  内容策划Agent                       │
│  → 结合主题+图片+账号定位            │
│  → 确定内容角度和故事结构            │
└──────────────┬──────────────────────┘
               │
               ▼
┌─────────────────────────────────────┐
│  文案生成Agent                       │
│  → 生成标题/正文/标签/封面文字       │
│  → 输出完整文案方案                  │
└──────────────┬──────────────────────┘
               │
               ▼
┌─────────────────────────────────────┐
│  优化审核Agent                       │
│  → 主题一致性检查                    │
│  → 违规风险检查                      │
│  → 风格一致性检查                    │
│  → 不通过则返回修改                  │
└──────────────┬──────────────────────┘
               │
               ▼
┌─────────────────────────────────────┐
│  主控Agent 整合结果                  │
│  → 打包输出给用户                    │
│  → 等待用户审核确认                  │
└──────────────┬──────────────────────┘
               │
               ▼
         用户审核确认后
               │
               ▼
┌─────────────────────────────────────┐
│  调度发布执行Agent                   │
│  → 传递素材包                        │
│  → 执行浏览器自动化发布              │
└─────────────────────────────────────┘
```

## MVP版本简化流程

当前 V1.x 版本中，部分 Agent 合并为一个内容生成引擎：

```
用户输入
  ↓
内容生成引擎（合并：图片分析 + 策划 + 文案）
  ↓
人设检查（简化版审核Agent）
  ↓
用户审核
  ↓
执行发布Agent（Playwright自动化）
```

V2.0 将按完整 Agent 架构拆分。
