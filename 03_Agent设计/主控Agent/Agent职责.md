# 主控Agent · Agent职责

> 版本：V1.0 | 基于 AI-Douyin-Agent Agent架构文档

---

## 1. Agent设计目标

本系统通过多个专业Agent协作，实现：

用户上传图片 + 输入主题

自动完成：

* 图片理解
* 内容策划
* 文案生成
* 内容优化
* 发布辅助

---

## 2. 整体Agent架构

```
用户

↓

任务管理Agent（主控）

↓

--------------------------------

图片分析Agent

内容策划Agent

文案生成Agent

优化审核Agent

发布执行Agent

--------------------------------

↓

发布结果
```

---

## 3. Agent职责设计

### 3.1 任务管理Agent（主控Agent）

角色：

AI项目调度员

职责：

* 接收用户需求
* 判断任务类型
* 调用对应Agent
* 整合最终结果

输入：

用户：

* 图片
* 主题
* 修改要求

输出：

任务流程。

---

### 3.2 图片分析Agent

角色：

视觉分析专家

任务：

理解用户上传图片。

输入：

图片文件

分析：

* 场景
* 人物
* 时间
* 情绪
* 故事线

输出：

```json
{
"image_description":"",
"emotion":"",
"story":"",
"order":[]
}
```

---

### 3.3 内容策划Agent

角色：

短视频策划专家

职责：

根据：

* 图片
* 用户主题
* 用户账号定位

设计内容方向。

输出：

* 内容角度
* 故事结构
* 用户痛点

---

### 3.4 文案生成Agent

角色：

抖音运营专家

职责：

生成：

标题：

正文：

标签：

互动话术：

封面文字：

要求：

符合平台表达习惯。

---

### 3.5 优化审核Agent

角色：

内容审核专家

检查：

* 是否符合主题
* 是否有违规风险
* 是否吸引用户
* 是否符合账号风格

输出：

优化建议。

---

### 3.6 发布执行Agent

角色：

自动化执行助手

职责：

调用浏览器自动化工具。

流程：

```
接收最终内容

↓

打开浏览器

↓

进入抖音创作者中心

↓

上传图片

↓

填写内容

↓

等待用户确认
```
