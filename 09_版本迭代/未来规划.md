# 未来规划

> V2.0 及更长远的规划方向

---

## V2.0 — 真 Agent 架构 📋

**目标：** 从"单体桌面应用"升级为"多智能体协作系统"。

### 架构升级

```
V1.x 单体应用                  V2.0 多Agent架构

app/main.py                    FastAPI 后端
  ├── generator.py   ──►        ├── 选题Agent
  ├── publisher.py              ├── 内容生成Agent
  └── audio.py                  ├── 审核Agent
                                ├── 发布执行Agent
                                ├── 复盘Agent
                                └── 数据分析Agent
```

### 新增 Agent

| Agent | 职责 | 优先级 |
|-------|------|--------|
| **选题Agent** | 分析热点+个人定位 → 推荐本周选题 | 高 |
| **复盘Agent** | 分析发布数据 → 给出优化建议 | 高 |
| **数据分析Agent** | 粉丝画像、互动趋势分析 | 中 |
| **热点追踪Agent** | 实时监测AI/编程领域热点 | 低 |

### 技术升级

| 组件 | V1.x | V2.0 |
|------|------|------|
| 前端 | tkinter | React Web UI |
| 后端 | 无（单体脚本） | FastAPI |
| 数据库 | JSON文件 + Excel | SQLite → PostgreSQL |
| Agent通信 | 文件系统桥接 | API + 消息队列 |

### 坚持不变的核心理念

无论技术如何演进，以下原则不变：

1. **AI 辅助，人做决策** —— 永远不自动发布
2. **真实记录** —— 不虚假包装
3. **简单易用** —— 3分钟内完成一次发布
4. **个人掌控** —— 用户拥有全部数据和内容
