# 私人AI创作助手 · AI 抖音创作智能体

> 一个 04 年出生的年轻人的 AI 项目记录 × 个人 IP 内容生产系统
> 输入本周主题 + 代码截图 + 若干生活/学习照 → 自动生成统一封面、打标签代码图、文案、BGM、发布计划

## 🚀 快速开始

**双击桌面快捷方式「AI 抖音创作智能体」** 即可打开。

或手动启动：

```bash
python 06_技术开发/app/main.py
```

## 📖 每周操作（3 分钟）

1. 打开程序，填写：周数、本周主题、学了什么、完成了什么、卡在哪
2. 照片上传：
   - **封面**：固定黑底模板（素材库 `07_数据资产/图片素材/第一张图片模板照片/`），智能体按期数+主题自动改，**不用传**
   - **代码截图**：点「＋ 🖥 代码/项目截图」上传（支持多张，每张自动打标签）
   - **生活照**：点「＋ 🏡📚 生活/学习照片」上传（可多选，排序交给智能体）
   - **管理**：点「📋 照片总览」查看全部、删除（右上角 ✕）/ 更换
3. 点「① 生成文案与方案」
4. 检查四个标签页（📝 文案 / 🖼️ 图片 / 🎵 音乐发布 / 🏷️ 标记）
5. 点「② 审核通过 · 填充到抖音发布页」→ 预览窗口审核后，智能体自动打开抖音上传图、填文案
6. 记录自动存档到 `07_数据资产/已发布内容/07_发布记录.xlsx`

## 🎯 项目定位

私人AI创作助手是一套面向个人创作者的内容生产自动化系统：

- **AI 学习记录**：每周学习内容系统化产出短视频内容
- **编程学习过程**：代码截图自动打标签，建立专业信任感
- **个人成长记录**：真实、不包装的成长轨迹

## 🔑 Token 最小化设计

| 模式 | 消耗 | 说明 |
|---|---|---|
| 离线模板引擎（默认） | **0 token** | 内置模板 + 规则引擎，断网可用，1 秒出结果 |
| API 润色（可选） | 约 800 token/次 | 参考 `06_技术开发/settings.example.json` 配置本地 `data/settings.json`，失败自动回退离线 |

## 🎵 BGM 智能匹配（自动 + 手动）

**自动匹配（默认）：** 智能体根据本周主题/情绪，从内置抖音热门曲库（14首）自动推荐 3 首最匹配的 BGM，并给出截取段落建议。

**手动上传（可选）：** 将音乐文件（mp3/wav/flac/m4a/ogg）放进 `07_数据资产/图片素材/BGM音乐/`，生成方案时智能体会额外分析音频能量曲线并截取30秒片段。

```bash
pip install pydub numpy imageio-ffmpeg -i https://pypi.tuna.tsinghua.edu.cn/simple
```

> 未装依赖时程序正常运行，BGM 推荐不受影响，仅跳过音频截取。

## 🧩 模块整合层（M1 · 产品整合方案落地）

| 模块 | 说明 |
|------|------|
| 📦 **素材包契约** `package.py` | 模块间唯一数据接口 `publish_package.json`：读/写/校验/摘要/富化，原子写入 |
| 🧠 **情绪分析** `analysis.py` | 0 token 从生成方案派生情绪/场景/标签，作为音乐模块标准输入 |

## 🛡️ 安全原则

- 发布前必须经过人工审核确认
- 不保存任何平台账号密码
- Cookie 通过 Playwright 持久化用户目录保存
- 限制自动操作频率
- 完整记录操作日志

## ❓ 常见问题

- **点开没反应？** 右键快捷方式 → 打开方式 → 选 Python；或命令行运行 `python 06_技术开发/app/main.py` 看报错
- **标签文字太小/太大？** 标签字号按图片宽度自动缩放，建议原图宽度 ≥ 720px
- **图片标签乱码？** 需要 Windows 系统字体微软雅黑（默认都有）
- **未登录提示？** 在自动打开的浏览器中扫码登录抖音创作者中心，登录完成后程序自动继续
