# 完整业务流程

> 智能体内部的工作流，也是你每周的操作清单。

## 每周节奏

| 时间 | 做什么 |
|---|---|
| 周一 | 确定本周学习主题 |
| 周二–周四 | 学习 + 写代码，随手拍 3 张照片放进素材库 |
| 周五 | 打开智能体 → 输入主题 → 一键生成 → 审核 → 发布 |
| 周日 | 看数据，把值得记的写进《爆款分析库》 |

## 智能体内部工作流（6 步）

```
收到主题
  ↓
① 分析主题（匹配内容模板库）
  ↓
② 生成视频结构（三张照片方案 + 镜头顺序）
  ↓
③ 生成文案（标题 / 钩子 / 正文 / 话题标签）
  ↓
④ 第二张图打「代码标签」（自动 P 到图上）
  ↓
⑤ 推荐背景音乐 + 发布时间
  ↓
⑥ 人设检查（对照《个人定位》红线，不通过就重写）
  ↓
打包成 output/第N周/ 文件夹 → 等你审核
  ↓
审核通过 → 文案进剪贴板 + 打开抖音创作者中心 → 记入发布记录
```

## 审核关卡（重要）

智能体**永远不会自动发布**。
所有内容必须经过你点「✅ 审核通过」才会进入发布流程。
你是内容的最终负责人。

## 完整端到端流程

```
用户输入（主题 + 照片）
      │
      ▼
┌─────────────────┐
│  内容生成Agent   │
│                 │
│  1. 分析主题     │
│  2. 生成文案     │
│  3. 打代码标签   │
│  4. 推荐BGM      │
│  5. 人设检查     │
└────────┬────────┘
         │
         ▼  素材包 (publish_package.json)
         │
┌────────┴────────┐
│   人工审核       │
│   (修改/确认)    │
└────────┬────────┘
         │
         ▼  审核通过
┌─────────────────┐
│  执行发布Agent   │
│                 │
│  1. 校验素材     │
│  2. 打开浏览器   │
│  3. 上传图片     │
│  4. 填写内容     │
│  5. 发布前自检   │
│  6. 等待确认     │
└────────┬────────┘
         │
         ▼
   抖音创作者中心
   (用户最终点击发布)
```
