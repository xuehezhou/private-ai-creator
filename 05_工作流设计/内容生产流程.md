# 内容生产流程

> 从主题输入到成品输出的完整流程设计

---

## 智能体内部工作流（6 步）

```
收到主题
  ↓
① 分析主题（匹配内容模板库）
  ↓
② 生成视频结构（三张照片方案 + 镜头顺序）
  ↓
③ 生成文案（标题 / 钩子 / 正文 / 话题标签）
  ↓
④ 第二张图打「代码标签」（自动 P 到图上）
  ↓
⑤ 推荐背景音乐 + 发布时间
  ↓
⑥ 人设检查（对照《01_个人定位》红线，不通过就重写）
  ↓
打包成 output/第N周/ 文件夹 → 等你审核
  ↓
审核通过 → 文案进剪贴板 + 打开抖音创作者中心 → 记入发布记录
```

---

## 文案公式（短句分行体）

```
{年龄}岁。

我开始认真学习AI。

第{N}周。

{这周做了什么 / 学会了什么}

{以前觉得……现在开始……}

下一步：
{下周计划}。
```

## 开头 3 秒钩子公式

三选一：
1. 数字成长型：「20岁，自学AI第N周。」
2. 提问型：「普通人自学AI，第N周能走到哪一步？」
3. 反差型：「上周还完全看不懂，这周我终于……」

## 话题标签固定组

`#AI学习` `#自学编程` `#20岁` `#成长记录` `#人工智能`

---

## 每周节奏

| 时间 | 做什么 |
|---|---|
| 周一 | 确定本周学习主题 |
| 周二–周四 | 学习 + 写代码，随手拍 3 张照片放进素材库 |
| 周五 | 打开智能体 → 输入主题 → 一键生成 → 审核 → 发布 |
| 周日 | 看数据，把值得记的写进《04_爆款分析库》 |

---

## 审核关卡（重要）

智能体**永远不会自动发布**。
所有内容必须经过你点「✅ 审核通过」才会进入发布流程。
你是内容的最终负责人。
