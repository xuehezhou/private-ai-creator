## 完整发布流程（11步）

```
用户点击"开始发布"
       │
       ▼
┌─────────────────────────────────────────────────────────┐
│                                                         │
│  STEP 1  ─── 加载素材包                                  │
│  │       读取 output/第N周/publish_package.json          │
│  │                                                      │
│  STEP 2  ─── 素材校验                                    │
│  │       图片存在？标题字数？标签合规？                     │
│  │       ❌ 失败 → 终止，返回错误报告                     │
│  │                                                      │
│  STEP 3  ─── 启动浏览器                                  │
│  │       Playwright Chromium 持久化上下文                 │
│  │       ❌ 未登录 → 提示用户扫码登录                     │
│  │                                                      │
│  STEP 4  ─── 导航至发布页                                │
│  │       → creator.douyin.com/creator-micro/content/    │
│  │       upload                                         │
│  │       ❌ 超时 → 刷新重试（最多3次）                    │
│  │                                                      │
│  STEP 5  ─── 上传图片                                    │
│  │       三级降级：文件input → 上传按钮 → AI坐标点击      │
│  │       ❌ 全部失败 → 截图 + 通知手动上传                │
│  │                                                      │
│  STEP 6  ─── 填写标题                                    │
│  │       定位输入框 → 清空 → 粘贴标题 → 验证              │
│  │                                                      │
│  STEP 7  ─── 填写正文                                    │
│  │       定位编辑器 → 清空 → 粘贴正文 → 验证              │
│  │                                                      │
│  STEP 8  ─── 添加标签                                    │
│  │       逐个输入标签 → 等下拉建议 → 回车确认             │
│  │                                                      │
│  STEP 9  ─── 添加BGM（音乐模块推荐）                     │
│  │       优先读取素材包 bgm_candidates（音乐模块输出）     │
│  │       三级降级：音乐入口选择器 → AI Vision → 手动指引  │
│  │       ⚠️ 失败不阻塞发布，输出搜索关键词供手动添加       │
│  │                                                      │
│  STEP 10 ─── 发布前自检                                  │
│  │       截图 → 对比图片数/标题/正文/标签/BGM             │
│  │       ❌ 不匹配 → 修正差异项                           │
│  │                                                      │
│  STEP 11 ─── 截图 + 通知                                 │
│  │       截取发布页 → 保存 → 摘要通知用户                 │
│  │                                                      │
│  ★ 停在发布确认页，等待用户手动点击"发布"                 │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

## 时序参考

```
操作                      耗时（估算）
────────────────────────────────────
加载素材包                  < 100ms
素材校验                    < 200ms
启动浏览器                  2-5秒
检查登录态                  1-2秒
导航至发布页                3-5秒
上传图片（3张）             20-40秒
填写标题                    1-2秒
填写正文                    1-3秒
添加标签（3个）             3-6秒
添加BGM（自动搜索）         5-12秒（失败则更快）

────────────────────────────────────
总计（预估）                40-80秒
```

## 三级降级策略（图片上传）

```
第一级：input[type=file] 直接设置文件
    │  选择器: input[type="file"][accept*="image"]
    │
    ├── 成功 → 继续下一步
    └── 失败 → 第二级
         │
第二级：点击上传按钮 + 文件选择对话框
    │  截图 → AI Vision识别上传按钮 → 点击
    │
    └── 失败 → 第三级
         │
第三级：纯AI Vision坐标点击
    全页截图 → 发给AI识别 → 坐标点击
    │
    └── 失败 → 停止，通知用户手动上传
```

## 三级降级策略（BGM 添加）

```
数据源：优先 bgm_candidates（音乐推荐模块输出，带匹配评分）
        回退 content.bgm（generator 旧版硬编码列表）

第一级：定位音乐入口（选择器数组）
    │  text="选择音乐"/"添加音乐"/"配乐" 等
    │
    ├── 成功 → 面板中搜索 search_keyword → 选中第一首 → 确认
    └── 失败 → 第二级
         │
第二级：AI Vision 识别音乐入口
    │  截图 → 发给AI识别入口按钮文字 → 点击 → 搜索
    │
    └── 失败 → 第三级
         │
第三级：手动指引（不阻塞）
    输出全部候选的抖音搜索关键词
    截图保存到 output_dir（BGM未添加_{时间戳}.png）
    继续后续自检/发布流程
```

**关键原则：BGM 失败不影响图片/标题/正文（核心内容），流程照常推进。**

## 人工确认点

V1.0 中，以下节点需要人工确认：

| 节点 | 确认内容 |
|------|---------|
| 发布前 | 审核素材包内容（标题/正文/标签/图片/BGM） |
| 登录态过期 | 扫码重新登录 |
| BGM 未自动添加 | 手动在抖音搜索推荐关键词添加音乐 |
| 发布最终页 | 检查填入内容 → 手动点击"发布"按钮 |
| 平台验证码 | 手动完成验证 |
