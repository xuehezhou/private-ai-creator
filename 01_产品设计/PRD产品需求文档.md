# PRD 产品需求文档

> 版本：V1.5 | 2026-07-31
> 基于 AI-Douyin-Agent 实际开发经验编写

---

## 一、产品概述

### 1.1 产品定位

**私人AI创作助手**是一套面向个人创作者的内容生产自动化系统。

帮助一个 20 岁正在自学 AI 的年轻人，用最少的时间和精力，将每周的学习成果转化为高质量短视频内容。

### 1.2 目标用户

| 用户画像 | 描述 |
|---------|------|
| **主要用户** | 20岁，正在自学AI/编程，想用短视频记录成长过程 |
| **核心痛点** | 每周花大量时间想文案、做封面、配BGM，创作门槛高 |
| **核心诉求** | 输入主题+照片 → 自动生成完整发布内容 → 一键发布 |

### 1.3 产品愿景

> 让每一个认真记录自己成长的人，都能拥有一个私人 AI 内容团队。
>
> 从选题 → 创作 → 发布 → 复盘，全流程智能化，但始终保持人的最终决策权。

## 二、功能需求

### 2.1 V1.5 当前功能

| 模块 | 功能 | 状态 |
|------|------|------|
| **内容生成** | 离线模板引擎（0 token） | ✅ |

## 三、非功能需求

### 3.1 性能

| 指标 | 目标 |
|------|------|
| 离线文案生成 | < 1秒 |
| API润色 | < 5秒 |
| 封面生成 | < 2秒 |
| 代码打标签 | < 3秒/张 |
| 发布自动填充 | 35-70秒 |

### 3.2 安全

- 发布前必须经过人工审核确认
- 不保存任何平台账号密码
- Cookie通过Playwright持久化用户目录保存
- 限制自动操作频率
- 完整记录操作日志

### 3.3 可用性

- 离线模式：断网时核心功能（文案生成/封面/标签）全部可用
- API模式：失败自动回退离线，不影响使用
- 草稿自动保存：防止意外关闭丢失内容

## 四、用户故事

### 故事1：每周发布

> 作为创作者，我周五打开应用，输入本周主题和3张照片，点一下按钮，1秒后文案、封面、标签全部生成。我快速检查一下，确认无误，点发布，浏览器自动帮我填好所有内容，我最后看一眼点发布就完成了。全程不超过3分钟。

### 故事2：代码学习记录

> 作为正在学编程的人，我上传一张代码截图，系统自动分析这段代码在做什么，在图片上打上标签"Python列表推导式"，让观众一看就懂我的学习内容，建立专业信任。

### 故事3：风格一致性

> 我不需要担心每期封面不一样，系统自动用固定模板生成封面，只改主题和期数。我的账号看起来整整齐齐，观众一眼就能认出我。
