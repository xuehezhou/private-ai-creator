# 功能规划 · 内容模板库

> 我的账号采用**固定版式**，保持统一风格，让粉丝一眼认出是我。
> 智能体每次生成内容都会严格按这个版式输出，并自动排版。

---

## 固定版式公式（程序自动排版，你只管上传）

### 第一张：封面 —— 固定模板，智能体按期数+主题自动改（你不用传）

- 作用：统一封面，让人愿意点进来，且**每期长一样**（账号辨识度高）
- 操作：封面**固定**用素材库「第一张图片模板照片」里那张黑底主题照；你只要在程序里填**期数+主题**，智能体会**读模板的底色+字色**，把「主题 + 期数 + 副标题」换上去 → 风格不变、内容每期更新
- 兜底：万一素材库那张不在，程序用内置设计稿渲染（深色品牌底 + 周数徽章 + 主题大字）
- 好处：你不用每期想封面、也不用每次选模板，改个主题就出图，整排作品整齐划一
- 参考来源：本套版式与文案节奏，参照你自己的爆款模板 + 同类爆火图文的叙事结构（封面定调 → 代码立信 → 生活/情绪推进）

### 第二张：代码学习照片 —— 负责建立信任（带标签）

- 作用：证明我真的在学、在做
- 内容：你上传 1 张电脑屏幕 / 代码编辑器 / 运行结果截图
- ⭐ 特殊要求：程序会自动在图上打「代码标签」，写明这段代码的含义
- 标签示例：
  - 这段代码在做什么
  - - RAG 检索增强生成
  - - 调用 DeepSeek API

### 第三张起：生活 / 学习照片 —— 程序按爆款节奏排版（可多张）

- 你点「＋ 🏡📚 生活/学习照片」一次选多张，**不用管顺序**，程序按爆款叙事节奏自动排：
  1. 学习过程 → 制造代入（让观众看见正在学的你）
  2. 生活松弛 → 拉近距离（学习之外的真实生活）
  3. 情绪高点 → 跑通 / 深夜瞬间，把情绪推上去
  4. 真实细节 → 一杯水 / 一摞书，细节最打动人
  5. 下一步钩子 → 留个悬念，让人想追更
- 内容示例：咖啡、散步、运动、夜晚的台灯、跑通代码的那一刻
- 想换 / 删 / 加：点「📋 照片总览」，每张**右上角 ✕ 删除**、小「更换」换图，底部两个按钮「＋ 代码 / ＋ 生活学习」添加

2. 提问型：「普通人自学AI，第N周能走到哪一步？」
3. 反差型：「上周还完全看不懂，这周我终于……」
