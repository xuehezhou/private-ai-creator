# 用户流程

> 完整的用户操作流程，从打开应用到内容发布

---

## 一、每周发布流程（主流程）

```
周五晚上，打开应用
      │
      ▼
┌─────────────────────────────┐
│ 填写本周信息（30秒）          │
│                             │
│ 周数：[30]                   │
│ 主题：[用AI学Python基础]     │
│ 学了什么：[列表推导式...]     │
│ 完成了什么：[写了桌面整理脚本]│
│ 卡在哪：[装饰器还不太懂]      │
└─────────────┬───────────────┘
              │
              ▼
┌─────────────────────────────┐
│ 上传照片（1分钟）             │
│                             │
│ 🖥 代码截图 [选择文件] ×2    │
│ 🏡 生活照片 [选择文件] ×3    │
│ 📋 照片总览 [查看/删除/更换] │
└─────────────┬───────────────┘
              │
              ▼
┌─────────────────────────────┐
│ 点击「① 生成文案与方案」     │
│ （1秒出结果）                │
└─────────────┬───────────────┘
              │
              ▼
┌─────────────────────────────┐
│ 审核结果（1-2分钟）          │
│                             │
│ 📝 文案页：查看/编辑文案     │
│ 🖼️ 图片页：查看生成图       │
│ 🎵 音乐页：查看BGM推荐      │
│ 🏷️ 标记页：调整标签设置     │
└─────────────┬───────────────┘
              │
              ▼
┌─────────────────────────────┐
│ 点击「② 审核通过·发布」     │
│ （自动打开浏览器填充内容）    │
└─────────────┬───────────────┘
              │
              ▼
┌─────────────────────────────┐
│ 浏览器中最终确认（30秒）     │
│                             │
│ ✅ 检查图片是否上传正确      │
│ ✅ 检查标题/正文是否完整     │
│ ✅ 检查标签是否添加          │
│ ⚠️ 确认无误 → 手动点「发布」 │
└─────────────────────────────┘
```

## 二、首次使用流程

```
首次打开应用
      │
      ▼
┌─────────────────────────────┐
│ 1. 确认素材库路径            │
│    默认：07_数据资产/图片素材/│
└─────────────┬───────────────┘
              │
              ▼
┌─────────────────────────────┐
│ 2. 放入封面模板照片          │
│    → 图片素材/第一张图片模板照片/│
└─────────────┬───────────────┘
              │
              ▼
┌─────────────────────────────┐
│ 3.（可选）填写API Key        │
│    data/settings.json       │
│    不开也能用（离线模式）     │
└─────────────┬───────────────┘
              │
              ▼
        开始第1周发布
```

## 三、修改内容流程

```
发布前发现文案需要改
      │
      ▼
┌─────────────────────────────┐
│ 方式1：GUI中直接编辑         │
│  → 📝 文案页 → 点击编辑 →   │
│    Ctrl+S 保存               │
│                             │
│ 方式2：编辑publish_package   │
│  → 打开JSON文件 → 修改字段 → │
│    重新点发布                 │
│                             │
│ 方式3：浏览器中手动改        │
│  → 发布Agent填充后 →         │
│    在浏览器中直接编辑 → 发布 │
└─────────────────────────────┘
```
